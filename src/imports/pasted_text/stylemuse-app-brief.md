Design a modern, premium, AI-powered fashion styling web application called **STYLEMUSE**.

The product is an AI personal stylist that helps users understand their clothing, create outfits, layer clothes, discover matching bottoms/accessories/shoes, plan outfits for occasions and trips, and find missing items through shopping recommendations.

The overall experience should feel like a combination of **ChatGPT + Pinterest + a premium fashion styling app**.

Do NOT make it look like a generic e-commerce website. The focus is **AI-powered personal styling and wardrobe intelligence**.

---

Create a sophisticated, feminine-but-inclusive fashion-tech interface.

Visual direction:

* Premium
* Minimal
* Elegant

* AI-focused
* Fashion editorial inspired
* Clean whitespace
* Rounded cards
* Subtle shadows
* High-quality clothing imagery

* Strong typography
* Minimal icons
* Smooth interactions

Suggested palette:

* Warm off-white / cream background

* Soft beige and muted neutral accents
* One subtle luxury accent color
* Avoid excessive pink or stereotypically feminine styling

Typography:

* Elegant modern heading font

* Large editorial headings
* Strong visual hierarchy

Use consistent:

* 8px spacing system
* Rounded buttons

* Subtle hover states
* Smooth transitions

**"How can I actually wear this?"**

The application must understand:

* Layering
* Innerwear
* Outerwear
* Color coordination
* Body proportions
* Face shape
* Accessories
* Footwear
* Occasion
* Weather
* Personal preferences
* Existing wardrobe
* Missing clothing
* Budget
